# Run の閲覧（リポジトリ詳細・Run 詳細・違反一覧）: 要件

リポジトリの最新の判定と直近の Run、1 つの Run の判定の中身、違反の一覧、取り込んだ成果物を見せる（S-02 / S-03 / S-04）。設計は [design.md](design.md)。

## ユースケース

| UC | 利用者 | シナリオ |
| --- | --- | --- |
| UC-03 | Admin | PR を計測し、Run 詳細で不合格の原因（どの関数、どの CVE、どのページ）を特定する |
| UC-04 | 全員 | リポジトリ詳細で、そのリポジトリの今の合否と直近の Run を確認する |

## 機能要件

| ID | 要件 |
| --- | --- |
| RUN-1 | Run 詳細で、6 カテゴリ × 各指標の実測値・しきい値・前回比・判定・判定理由を示す。部分計測では未計測の指標と理由を併記する |
| RUN-2 | 各指標から個別違反（脆弱性、複雑度超過関数、失敗したテスト、a11y 違反など）の一覧へ進め、ファイルを指す違反は対象リポジトリの該当ファイル・行の GitHub リンクを開ける |
| RUN-3 | 比較対象 Run と比べて、違反が新規 / 継続 / 解消 / 初回のどれかを示す |
| RUN-4 | 処理失敗（`FAILED`）の Run は、判定表の代わりに原因と対処を示す。不合格（`FAIL`）と見分けがつくようにする |
| RUN-5 | 取り込んだ元の成果物をダウンロードできる（保持期間内） |

## 受け入れ基準

- 収集ランナーが確定した Run の詳細で、6 カテゴリの判定を確認できる
- 部分計測の Run では「部分計測」と未計測の指標・理由が表示される
- M-08 の行には、判定によらず自動検査の限界の注記が出る
- 保持期間を過ぎた成果物は「削除済み」と表示され、ダウンロードできない
