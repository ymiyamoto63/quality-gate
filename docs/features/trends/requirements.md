# トレンド: 要件

指標の推移をグラフと表で示す（S-05）。設計は [design.md](design.md)。

## ユースケース

| UC | 利用者 | シナリオ |
| --- | --- | --- |
| UC-04 | 全員 | リポジトリの指標が良くなっているか悪くなっているかを、直近 30 日の推移で確認する |

## 機能要件

| ID | 要件 |
| --- | --- |
| TREND-1 | 指標ごとの時系列を示す。期間の既定は 30 日、最大 2 年 |
| TREND-2 | 値どうしを比べられない計測（コンポーネント、M-02 の実行範囲、性能の計測環境）は別の系列に分ける |
| TREND-3 | `SKIP` と計測エラーは 0 ではなく欠測として描く |
| TREND-4 | しきい値の線を重ね、期間内にしきい値が変わったことが分かるようにする |
| TREND-5 | グラフと同じ値を表でも見られる |

## 受け入れ基準

- 部分計測の Run の点が 0 として描かれない
- 計測環境の名前を変えた性能の値が、前の値と同じ線で結ばれない
- グラフはキーボードとスクリーンリーダーで内容を読める
