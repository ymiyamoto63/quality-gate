# 管理（利用者と監査ログ）: 要件

許可リストとロールを管理し、重要な操作を監査ログに残す（S-07）。設計は [design.md](design.md)。

## 機能要件

| ID | 要件 |
| --- | --- |
| ADMIN-1 | Admin は許可リストに GitHub ユーザーを追加し、ロール（Admin / Viewer）と状態（有効 / 無効）を変えられる |
| ADMIN-2 | 許可リストとロールの変更、最初の Admin の登録、再評価の依頼、リリース判定の CSV 出力を監査ログに記録する。監査ログは追記のみとする |
| ADMIN-3 | Admin は監査ログを期間と操作の種類で絞り込んで閲覧できる |
| ADMIN-4 | 有効な Admin が 0 人になる変更と、自分自身の降格・無効化はできない |

## 受け入れ基準

- 許可リストに追加した利用者が GitHub でログインできるようになる
- 利用者を無効化すると、その利用者は次のリクエストから操作できなくなる
- 最後の Admin を降格・無効化しようとすると 409 で拒否される
- 監査ログの行はアプリから更新・削除できない（アプリ専用のロールで運用する場合）
