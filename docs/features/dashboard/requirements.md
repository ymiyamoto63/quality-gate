# ダッシュボード: 要件

全リポジトリの今の合否を 1 画面で示す（S-01）。設計は [design.md](design.md)。

## ユースケース

| UC | 利用者 | シナリオ |
| --- | --- | --- |
| UC-04 | 全員 | ダッシュボードで全リポジトリの合否を確認し、問題のあるリポジトリの詳細や推移へ進む |

## 機能要件

| ID | 要件 |
| --- | --- |
| DASH-1 | 全リポジトリについて、最新の判定（完全計測か部分計測か）を示す |
| DASH-2 | 最終計測日時と、最後の完全計測の日時を示す（部分計測が続いても、全指標を最後に測った時点が分かるようにする） |
| DASH-3 | 問題のあるリポジトリを先頭に並べる |
| DASH-4 | 開いたままでも新しい計測結果が反映される |

## 受け入れ基準

- 部分計測の Run が最新でも、最後の完全計測の日時が常に表示される
- 不合格のリポジトリが合格のリポジトリより前に並ぶ
- ダッシュボードから 3 クリック以内で、各リポジトリの今の合否と 30 日の推移にたどり着ける
