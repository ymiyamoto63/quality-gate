# 合格ライン: 要件

何を合格とするか（しきい値と、判定する指標）を決める。設計は [design.md](design.md)。

## 機能要件

| ID | 要件 |
| --- | --- |
| CFG-1 | 合格ラインはアプリの環境変数（`QG_*`）で持つ。書かなかった項目は既定値（[指標](../../metrics.md#1-指標の一覧)） |
| CFG-2 | 判定しない指標を `QG_DISABLED_METRICS` で指定できる |
| CFG-3 | 値の形式が不正なら起動に失敗し、どの変数が誤っているかを示す |
| CFG-4 | 判定に使った合格ラインを計測ごとに残し、後から変えても判定済みの結論が変わらない |

## 受け入れ基準

- `QG_BRANCH_COVERAGE_MIN=80` にして再起動すると、その後の計測は 80% で判定され、画面の合格ラインが「≥ 80%」になる。以前の計測の結論と合格ラインは変わらない
- `QG_DISABLED_METRICS=M-03,M-04` にすると、M-03 / M-04 が判定にも画面にも現れない
